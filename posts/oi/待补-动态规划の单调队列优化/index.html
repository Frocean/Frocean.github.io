[待补] 动态规划の单调队列优化

📅 2018-09-20

最近又在搞 dp 了, 准备学习一些神奇的优化方法, 包括剪枝, 单调队列, 斜率优化之类的.

大多都不会, 放几道题目以后慢慢回来理解.

题目1

#include <cstdio>
int dp[200010],v[200010],pre[200010];
int h = 1,t = 1,ans = -0x7fffffff;
int max(int x,int y) {return x > y ? x : y;}
int main()
{
	int n,l,r;
	scanf("%d%d%d",&n,&l,&r);
	for (int a = 0 ; a <= n ; ++ a) scanf("%d",&v[a]);
	for (int a = l ; a <= n ; a ++)
	{
		while (pre[h] < a - r) ++ h;
		while (h <= t && dp[pre[t]] <= dp[a - l]) -- t;
		pre[++t] = a - l;
		dp[a] = dp[pre[h]] + v[a];
	}
	for (int a = n - r + 1 ; a <= n ; ++ a) ans = max(ans,dp[a]);
	printf("%d",ans);
}
