## 扩展欧几里得

首先我们要知道欧几里得是什么——某求最大公约数(Greatest Common Divisor, GCD)的东西 这个东西如果不知道......那我真没办法了 赶快先去看了再回来吧

好了那拓展欧几里得是什么呢？就是 Extended Euclidean algorithm(ExGCD)

好吧其实名称不重要 我们来看看这东西的用处..似乎只是用来求 $ax + by = gcd(a,b)$ 的？当然 但是有许多其他式子(我也没找几个)如 $ax \equiv 1 \pmod{b}$ 就可以转化为这种形式求解

后面那个式子就是我这篇要讲的题 [链接丢这里先 后面再放一个](https://www.luogu.org/problemnew/show/P1082)

先看看怎么转化

$ax \equiv 1 \pmod{b}$ 挪一下就是 $ax \bmod {b} \equiv 1$ 然后 $ax \bmod {b}$ 就是 $ax \div b$ 取余 也就是 $ax - b * (ax \div b) = 1$ (这里的 $\div$ 是取整)

然而这样并不好求 我们设和 $b$ 相乘的一大坨东西为 $y$ 则有 $ax - by = 1$ 也就是 $ax + (-by) = 1$

这里 y 怎么是个负数呢 实际上我们不用管那么多 因为最后求的解 $x$ 时是 $ax = 1 + by$ 而在 $\bmod {b}$ 意义下 $by \equiv 0$ 所以最终得到的还是 $ax \equiv 1 \pmod{b}$ 的解

我们已经转化到了 $ax + by$ 的形式 而原式就是要 $ax + by = 1$ 而当 $a, b$ 已知 那我们就可以很容易注意把 $ax + by$ 换成 $gcd(x, y)$, 而非继续考虑 $gcd(a, b)$

从而得到 $gcd(x, y) = 1$

没错！！！我们的拓展欧几里得可以派上用场了

好吧拓展欧几里得是什么都没说呢 ~~现在开始讲解~~就是一个式子好像没什么要讲的 直接推导然后应用就好了 (其实要讲的就是这些 讲完以后就懂了) 总之看完下面就懂了

欧几里得是干嘛的？辗转相除 (当然还有相减不过我们这边不管) 嘛

拓展欧几里得呢？看样子肯定也是差不多的辗转相除 那么具体有什么用呢

因为这里 $gcd = 1$ 所以 $x$ 和 $y$ 的最大公约数为 $1$ 通过普通欧几里得可以发现 此时两数一个是 $1$ 另一个是 $0$

然后拓展欧几里得里如果知道了这些 那方程里就少了两个未知数 然后当题中给定已知的 $a$ 和 $b$ 那完全就没有未知数了嘛

然后我们利用扩展欧几里得反过来回溯 就能得到我们想要的结果了~~

---

下面证明一下可行性 首先

- $ax + by = gcd(a,b)$
- $ax' + (b \bmod {a})y' = gcd(a, b \bmod {a})$
 
显然 $gcd(a,b) = gcd(a,b \bmod {a})$ 即 $ax + by = ax' + (b \bmod {a})y'$

那我们根据欧几里得最后就得到了 $x = 1$, $y = 0$ 于是次数方程变成 $1 * a + 0 * b = gcd(a,b) = a$ 这推到底的解就出来了

那我们考虑推回去 因为上一层的 $a = a$, $b = b \bmod {a}$

哦不 欧几里得的辗转相除每层的 $a$ 和 $b$ 都是反过来的

因为两个数的大小问题 $b > a$ 但是 $b \bmod {a} < a$ 要反过来 所以应该是 $b = a$, $a = b \bmod {a}$

但是我们要求的是 $x$ 和用来辅助的 $y$ 而简单地根据乘法交换律 我们不变 $a$ 和 $b$ 变 $x$ 和 $y$

像推 $a$ 和 $b$ 一样 然后利用每层递归的 $a$ 和 $b$ 的值 就可以找到原来的 $x$ 和 $y$ 了

但原来的那个是一个特解 如果像本题一样找最小的 就要像下面代码一样 如果找第 $k$ 小的 就用最小解乘上 $k$ 就好啦

## 乘法逆元

拓展欧几里得的这种用法 又可以说是求乘法逆元 不过乘法逆元的定义可能和上面那式子不太一样

- 若 $a * x \equiv 1 \pmod {b}$, 且 $a$ 与 $b$ 互质, 那么 $x$ 为 $a$ 的逆元 $x$ 也可表示为 $a^{-1}$, 也称 $x$ 为 $a$ 的倒数.

( 后面讲的时候 $b$ 换成 $p$ 因为题目原因 )

就像上面那个求就好了 但注意一点


  比如说 $4 * 3$ 在 $\bmod {11}$ 的意义下 $3$ 是 $4$ 的乘法逆元

  然而 $4 * 14$ 在 $\bmod {11}$ 的 意义下 $14$ 也是 $4$ 的乘法逆元
 
  但是 $14$ 在 $\bmod {11}$ 意义下 就是 $3$ 因为 $14 = 11 + 3$

  所以如果要求乘法逆元 输出的只有一个

好了好了 就像上面那程序一样就求得出来了 完全一样

但如果我们要求线性的解呢？比如[这道题目](https://www.luogu.org/problemnew/show/P3811) 像上面那样一个个跑绝对会炸掉的

那我们就需要线性算法 这个要推一个式子

首先 $1$ 的乘法逆元肯定要先弄出来 很显然 $1^{-1} = 1$ 了 也就是 $1^{-1} \equiv 1 \pmod {p}$

且当 $p > 1$ 时 还有一个前提条件 线性算法只能求 $p$ 为质数时 $x \in [1, p - 1], x \in \mathbb{Z}$ 的乘法逆元

因为这个条件 我们设 $p$ 是由一堆数构成的 因为 $p$ 又是质数 所以要分解成 $k$ 倍的 $i + r$ 的形式

即 $p = k * i + r,r < i,1 < i < p$ 其中 $r < i$ 是因为 $r \geqslant i$ 时 $r$ 可以化成 $i$ 的 倍数

指定 $i$ 为当前需要求的数 则其乘法逆元为 $i^{-1}$

我们可由 $p \bmod {p} = 0$ 得到一个式子

$k * i + r \equiv 0 \pmod {p}$

接下来转化 同乘 $i^{-1}r^{-1}$(就是同除 $ir$ 得

$k * r^{-1} + i^{-1} \equiv 0 \pmod {p}$

$i^{-1} \equiv - k * r^{-1} \pmod {p}$

此时将右边两项分开 $k = p / i$ 并且 $r = p \bmod {i}$ 此时指数不变 见下

$i^{-1} \equiv - \left \lfloor \frac{p}{i} \right \rfloor * (p \bmod {i})^{-1} \pmod {p}$

此时 $(p \bmod {i})^{-1}$ 是 $p \bmod {i}$ 这个数的逆元 这个数必定小于 $i$ 因此我们早已求出

这时候我们可以得到第一种式子

`ans[i] = -p / a * ans[p % a] % p`

然而这个式子是错的 因为会有负数 所以要改成下面那样 原理和上面拓展欧几里得的代码一样

`ans[i] = ((-p / a * ans[p % a]) % p + p) % p`

然后这样就可以跑了 实测556ms(当然别忘了要开 long long)

下放代码



### 代码(乘法逆元)

```cpp
#include <cstdio>
#define ll long long
const int MAXN = 3000010;
int ans[MAXN],n,p;
int main()
{
    ans[1] = 1; scanf("%d%d",&n,&p);
    for (int i = 2 ; i <= n ; ++ i)
		ans[i] = ((- (ll)p / i * ans[p % i]) % p + p) % p;
    for (int i = 1 ; i <= n ; ++ i)
		printf("%d\n",ans[i]);
    return 0;
}
```



### 扩展

还有 其实我们可以继续推下去

看一下我们之前的 $-\left \lfloor \frac{p}{i} \right \rfloor$ 通俗一点就是 $-\frac{p}{i}$

看好了 在 $\bmod {p}$ 意义下 这个项和下面那个项相等——

$p - \frac{p}{i} \pmod{p}$

为什么呢？

因为我们可以先把前面的 $p \bmod {p}$ 就是 $0$ 那下面那个式子就变成 $-\frac{p}{i}$ 了

众所周知 除 比 取模 要快上一些

于是我们可以得出下面这个式子

`ans[i] = (p - p / i) * ans[p % a] % p`

于是我们拿下面这个式子跑 实测470ms(当然要开long long)

下放代码

```cpp
#include <cstdio>
#define ll long long
const int MAXN = 3000010;
int ans[MAXN];
int main()
{
	int n,p;
	ans[1] = 1;
	scanf("%d%d",&n,&p);
	for (int i = 2 ; i <= n ; ++ i)
		ans[i] = (ll)(p - p / i) * ans[p % i] % p;
	for (int i = 1 ; i <= n ; ++ i)
		printf("%d\n",ans[i]);
	return 0;
}
```
